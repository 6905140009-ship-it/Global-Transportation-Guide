
# Project Charter
## Global Transportation Guide Website

### 1. Project Overview
The Global Transportation Guide Website is a website designed to help travelers understand transportation options in different countries and cities. It provides useful transportation information in one place so users can plan their journeys more easily.

### 2. Problem Statement
Travelers may find it difficult to understand public transportation systems in unfamiliar countries. Information about routes, transportation types, fares, and travel options can be difficult to find. This website aims to make transportation information easier to access and understand.

### 3. Project Objectives
- Provide transportation information for different countries and cities.
- Help users find suitable transportation options.
- Make travel planning easier and more convenient.
- Present information through a simple and user-friendly website.

### 4. Project Scope

**In Scope**
- Search for countries and cities.
- Display available transportation types.
- Provide route and transportation information.
- Show estimated fares when information is available.
- Provide useful travel tips.

**Out of Scope**
- Booking transportation tickets.
- Making online payments.
- Real-time vehicle tracking.
- Managing actual transportation services.

### 5. Target Users
- Tourists
- International students
- First-time travelers
- People who want to explore transportation in other countries

### 6. Main Deliverables
- A functional Global Transportation Guide Website.
- Transportation information pages.
- Search and navigation features.
- Project documentation.
- Database design.

### 7. Stakeholders
- Project team members
- Project instructor
- Website users

### 8. Assumptions
- Users have access to the internet.
- Transportation information can be collected from reliable sources.
- Users can access the website through a web browser.

### 9. Constraints
- Limited project development time.
- Limited team resources.
- Transportation information may change over time.

### 10. Success Criteria
- Users can easily search for transportation information.
- The website displays clear and useful information.
- The website is easy to navigate.
- The main features work as expected.

### 11. Conclusion
The Global Transportation Guide Website aims to make transportation information easier to find and understand. It will help travelers explore transportation options and plan their journeys with greater confidence.
