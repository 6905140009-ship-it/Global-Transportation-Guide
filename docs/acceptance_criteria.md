
# Acceptance Criteria
## Global Transportation Guide Website

### 1. Introduction
This document defines the conditions that must be met for the Global Transportation Guide Website to be considered complete and acceptable.

### 2. Homepage
- [ ] The homepage displays the website name.
- [ ] The homepage displays the main navigation menu.
- [ ] Users can access the main sections of the website.

### 3. Search Countries and Cities
- [ ] Users can enter a country or city in the search field.
- [ ] The system displays matching results when available.
- [ ] The system displays a helpful message when no results are found.

### 4. Transportation Information
- [ ] Users can view available transportation types.
- [ ] Each transportation option displays clear information.
- [ ] Users can find route information when available.

### 5. Fare Information
- [ ] The website displays estimated fares when available.
- [ ] Fare information is clearly presented.
- [ ] Users can understand when fare information is unavailable.

### 6. Travel Tips
- [ ] Users can view useful transportation tips.
- [ ] Travel tips are easy to read and understand.

### 7. Website Navigation
- [ ] Navigation links work correctly.
- [ ] Users can move between website pages easily.
- [ ] The website does not contain broken navigation links.

### 8. Usability and Compatibility
- [ ] The website has a clear and user-friendly layout.
- [ ] The website can be viewed on desktop and mobile screens.
- [ ] Text and information are easy to read.

### 9. Overall Acceptance
The project will be accepted when all required features work as expected, the information is displayed clearly, and the website meets the agreed project requirements.

### 10. Conclusion
These acceptance criteria will be used to check whether the Global Transportation Guide Website meets its requirements and is ready for demonstration.
